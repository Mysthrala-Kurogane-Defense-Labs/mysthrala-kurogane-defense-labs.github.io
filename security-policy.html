Política de seguridad

Mysthrala Kurogane Defense Labs mantiene un canal público para reportes de seguridad y vulnerabilidades.

Reporte de vulnerabilidades

Envía reportes a security@mkdl.jp.

Incluye, si es posible: producto o repositorio afectado, versión o commit, impacto estimado, pasos de reproducción seguros y evidencia sin secretos.

Objetivos de respuesta

PasoObjetivo operativo
Acuse de reciboHasta 3 días hábiles.
Triage inicialHasta 10 días hábiles.
Vulnerabilidades críticasGestión prioritaria inmediata con mitigación, workaround o parche en cuanto sea técnicamente viable.
Divulgación coordinadaDespués de mitigación/parche, salvo explotación activa o riesgo grave para clientes.

Repositorios públicos

Los repositorios públicos de Kurogane contienen documentación, SDKs, ejemplos sintéticos y modelos de seguridad. No contienen el core privado de producción de Kurogane Hub, credenciales, despliegues de clientes ni datos reales de planta.

Para vulnerabilidades específicas de un repositorio público, puede usarse GitHub Security Advisory cuando esté disponible. Para información sensible, usa siempre security@mkdl.jp.

Límites de claim
